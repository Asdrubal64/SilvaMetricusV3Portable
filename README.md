# SilvaMetricusV3Portable

This repository distributes **Silva Metricus version 3** as a portable application.

Silva Metricus is a forest inventory application for regression calculations,
biodiversity indices, stand tables, double-entry tables, and change calculations
between measurements.

## Portable edition

Use the portable release to run the application without a system-wide
installation. Extract the downloaded package and run the application from the
directory containing the extracted files.
